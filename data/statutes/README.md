# State HOA statute seeds

These `<state>.jsonl` files are **starter fixtures**, not comprehensive ingestion of
each state's HOA statutes. They exist so the Module 8 / W30 pipeline can be
exercised end-to-end. Before relying on the State Law Brain in production:

1. **Replace each file with full statute text** from the authoritative legislative
   source for that state (see `source_url` on each record below for the right
   starting point).
2. **Have the result reviewed by counsel licensed in that state**, especially
   the `title` and `category` fields — those drive the topic browser and Q&A
   retrieval and should match accepted topical taxonomies.
3. Re-run `pnpm exec tsx scripts/ingest-state-statutes.ts <STATE>` after
   replacing the file. The ingest is idempotent and overwrites chunks.

## Georgia snapshot

The snapshot header records every source document (URL, sha256, retrieval date) and the amendments checked.
Today it is the State's own electronic O.C.G.A. release 86 (Nov. 2022, via Public.Resource.Org), with Ga. L. 2024
HB 220 applied to §§ 44-3-223, 44-3-230 and 44-3-231(a), the Code-revision Acts Ga. L. 2025 SB 153 (§§ 44-3-230(b),
231(a)(4)) and Ga. L. 2026 HB 1268 (§§ 44-3-221, 225, 226, 234; BL-169), plus Ga. L. 2026 SB 406 § 7 as its own record.

SB 406 §§ 2–6 take effect 2027-01-01. They are carried as DATED records (BL-154): §§ 44-3-222, 44-3-226,
44-3-232 and 44-3-235 appear a second time with `@effective_date: 2027-01-01` (the release-86 text with the Act's
revised subsection swapped in), and `Ga. L. 2026, SB 406, § 2` (new ch. 43-17A) appears with that date only. The
adapter serves, per citation, the latest record whose effective date has arrived, so the weekly refresh switches to
the 2027 text by itself. Their text comes from `scripts/fixtures/state-law/ga-sb406-2026-2027-text.txt`, the
official bill PDF with struck words removed and underlined words kept (its header records how, and the check that
rebuilding the old text reproduces release 86).

The snapshot carries `@valid_until: 2027-07-01`, the usual effective date of the 2027 session's Acts. From that date
the GA adapter refuses to serve it: the refresh job reports GA as failed and the loaded rows stay as they are. Before
then, check the 2027 session for Acts amending Article 6 (or ch. 43-17A) and refresh:

1. Get the current text of each changed section: the Act as passed on legis.ga.gov (struck text removed,
   underlined text kept, applied to the snapshot's current text), or a newer State release of Title 44 if
   Public.Resource.Org publishes one (https://archive.org/details/gov.ga.ocga.2018). Compare against the
   official Code (LexisNexis public access, via legis.ga.gov → "Georgia Code"). A change that takes effect later
   can go in as a dated record (`@effective_date`), as SB 406 §§ 2–6 did.
2. Edit the snapshot: section text (one paragraph per line), its `@source_url`, `@effective_date` and `@history`;
   the header's source list; `@retrieved`; and `@valid_until` (the next known effective date of an Act not yet
   applied, or a date about a year out). When the Code places SB 406 § 7, move its text into that section and
   delete the `Ga. L. 2026, SB 406, § 7` record — the next refresh supersedes it.
3. Run `pnpm exec tsx scripts/build-ga-statute-snapshot.ts`, then the unit tests (georgia.test.ts pins the
   section list and a few known passages — update them to the new law).
4. Ship, then trigger the GA refresh (OA-9 in docs/owner-actions.md).

reproduces the current text, then update the header.

## File format

One JSON object per line. Lines beginning with `//` are ignored as comments.

```json
{
  "code_citation": "O.C.G.A. § 44-3-232",
  "title": "Meetings of association",
  "category": "meetings",
  "body": "<full statute text>",
  "source_url": "https://law.justia.com/...",
  "effective_date": "2024-07-01"
}
```

### Categories (recommended)

Use a consistent taxonomy across states so the topic browser groups correctly:

- `meetings` — annual / special / open meetings, notice, quorum
- `assessments` — regular / special / emergency assessments, payment
- `fines` — fines, suspensions, hearings
- `foreclosure` — liens, foreclosure, redemption
- `records` — owner inspection, retention, board minutes
- `architectural` — ARC, design review, approvals
- `fair_housing` — accommodations, discrimination
- `amendments` — declaration / bylaw amendments, governance changes

Use `null` (or omit the field) when the statute doesn't fit one of these.
