## What's new

### Violations
- A violation's page lists the home's earlier violations. Ones in the same category come first, then the newest, up to 10, with a link to the full list.
- When you start a new violation and pick a home, a line shows how many earlier violations it has. On the review step, it also shows how many are in the same category.

### ARC
- A new count, "Approved, past completion date", shows approved projects whose planned completion date has passed. It opens a filtered list. The list also shows each project's planned completion date.

### Events
- Counts at the top: events in the next 30 days, reminders due today, paused reminders, and past events that were never reminded.

### Website
- New page: /guides/texas-hoa-written-ballots-209-0058

## Fixes

- **Dues reminders, monthly board reports and scheduled announcements.** If any of these fails for an association, the team now gets a report. Before, failures were only noted in the logs.
- **Stuck announcements.** A scheduled announcement still stuck on "sending" after 30 minutes is flagged to the team. Nothing is resent automatically.
