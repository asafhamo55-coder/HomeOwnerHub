## Fixes

- **Expired sign-in links.** A reset or sign-up link that has expired, or was already used, now says so and offers a new link. Before, it showed a plain sign-in page.
- **Invite links.** Some invitation links deliver the sign-in in a way the app could not read, so the person landed on the sign-in page. The app now finishes signing them in, then sends them only to a page on this site.
- **New violation.** The CC&R reminder now says "Upload your CC&Rs" and links to the right page. It shows at the start and no longer appears by mistake when the check itself fails.
- **Offline page.** "Try again" reloads the page you were on, instead of going home.

## What's new

### Dues
- Before you generate a month's dues, the dialog shows how many homes will be billed, the amount for each, the total and the due date. It also says how many homes already have this month's dues and will be skipped.
- There's no made-up default amount anymore. If no dues rate is set, the field is blank with a link to set one.
- After generating, the message says how many homes were billed.

### After a roster import
- The finished screen suggests next steps: invite owners (with how many rows had an email), generate dues, and send a first announcement.

### Announcements
- Before you write a message, the page shows how many homes can actually be reached by email or text. If none can, it says so up front, with links to add contact details.
