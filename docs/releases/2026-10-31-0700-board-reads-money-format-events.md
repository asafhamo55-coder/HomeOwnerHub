title: Clear errors on board tickets and attachments, consistent dollar amounts, and a quick start for the calendar
---

## Fixes

- **Board ticket page.**
  - If a ticket can't load, the page now says so and offers Try again, instead of "not found".
  - If only the conversation can't load, the ticket shows "Couldn't load the conversation" and hides the reply box. This way nobody answers a thread they can't see.
- **Attachments.**
  - On tickets, ARC requests and violation reports, a failed load now says "Couldn't load attachments. Try again". Before, it looked as if no files were attached.
  - A single file whose link fails shows "Link unavailable". The other files still open.
- **Dollar amounts.**
  - Balances now show a thousands comma: $1,250.00, not $1250.00.
  - Daily fines read "$12.50 a day", not "$12.5".
  - Proposed fines in the approval queue keep their cents.
  - A new check keeps every screen on the same format.

## What's new

### Events
- An empty calendar shows "Common deadlines" chips: Annual meeting, Insurance renewal, Budget adoption, Reserve study review, Audit or financial review. Georgia associations also get Georgia annual registration.
- Each chip opens a new event with the title filled in. You still review and save it.
