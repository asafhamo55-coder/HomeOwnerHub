---
title: The Approvals count on your dashboard now matches Things to approve
---

## Summary

The Approvals tile on the dashboard used to miss some kinds of requests, so it could say "Inbox zero" while Things to approve had requests waiting. It now counts every request type on that page.

## What's new

### Boards
- The Approvals count on the dashboard covers every request type: amenity bookings, requests to join, contact updates, scanned bills, letters, ARC reviews and the rest. It always equals the number on Things to approve, and so does the sidebar badge.
- The tile now opens Things to approve. If some items could not be counted, it says so instead of showing a false zero.
- The older list of drafts (violation letters, meeting minutes, invoices, RFPs) is now called "Drafts to finish" and is counted separately.
