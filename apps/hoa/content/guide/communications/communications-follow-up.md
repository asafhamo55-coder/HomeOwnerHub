Use this a day or two after an announcement, when some homes still haven't opened it. The follow-up goes only to those homes, so everyone else isn't emailed twice.

## Before you start
- The message must already be sent. A follow-up is offered for messages to all homes, all owners, homes behind on dues, homes with an open violation, a street or one home.

## Steps
1. Open **Messages**, then the **Sent to residents** tab, and select the message.
2. Under **Did people get it?**, read how many homes haven't opened the email.
3. Select **Email again to the … who haven't opened**. To text them instead, select **Text them**.
4. A new message opens with "Reminder:" before the subject, the same body, and those homes as the audience. Read it and change anything you like.
5. If a box asks you to fill in details, like a due date, fill them in.
6. Check the phone preview, then select [[Send now]].

## What happens next
The reminder is a new message under **Sent to residents**, with its own results. The first message and its figures don't change. Nothing goes out until you select Send. If you leave without sending, the reminder stays in the [[Drafts]] tab once you've changed something.

## If something goes wrong
- "No follow-up to send": every home has opened it, or its audience can't be followed up this way. You can still write a new message.
- "This follow-up is no longer available. Pick an audience.": pick the audience yourself, or go back to the first message and start the follow-up again.
- **Text them** isn't there: texting isn't set up for your HOA. Use **Email again** instead.

## Good to know
- Opens are approximate. Some mail apps open every email on their own, and some block the count. A home may have read it and still show as not opened.
- A text never opens, so a home that only got a text never counts as not opened.
- **Text them** only reaches residents who agreed to get texts. Other people in those homes get nothing, unless you also tick **Email**.
- A follow-up isn't offered for messages to renters only, the board or someone outside the HOA.
- The Spanish version isn't copied. Select [[Add Spanish version]] again if you want it.
- Answers to a template's questions aren't stored, so a reminder may ask for them again.
