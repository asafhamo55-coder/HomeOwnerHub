HomeownerHub writes the letter and the board approves it, but it does not mail anything for you yet. You print the approved letter and mail it yourself. Mailing from inside the app comes later.

## Before you start
- Board members and admins can approve, print and mail letters.
- Approving does not mail anything. It only makes the letter ready.

## Steps
### A collections letter
1. Draft the letter on the home's page and send it to Approvals. See [draft a collections letter](guide:dues-collections-letter).
2. A board member opens **Approvals** and selects [[Approve letter]]. The message says "Letter approved. Print it from the property’s collections letter page and mail it yourself. Nothing was sent."
3. Open **Properties**, open the home, and select [[Draft collections letter]]. Tick [[I’ve verified these figures]], then select [[Print / Save as PDF]].
4. Sign the letter if it needs a signature, put it in an envelope with the address on file, and mail it. Use certified mail if the letter says it must go that way.

### A violation letter
1. Report the violation and approve the letter. See [report a violation](guide:violations-report-and-letter).
2. Open the violation. The approved letter is under **Notice as sent**.
3. Under **Notice as sent**, select [[Print / Save as PDF]]. A clean page opens with the association name, the date, the owner's name and address, and the full letter. Select [[Print / Save as PDF]] again to print it or save it as a PDF. Mail it yourself.

## What happens next
- Printing a collections letter records it on the collections case, dated the day it prints.
- A violation letter is already on record once approved. Printing it from the button is also recorded in the audit log. Mailing it is up to you.
- If you mail on a later day than you print, add a note to the case with the mailing date.

## If something goes wrong
- The printout is marked as a draft and not valid: use the [[Print / Save as PDF]] button on the approved letter, not your browser's Print command.
- "The account has changed since this letter was approved": a payment or charge was recorded after approval. Select [[Draft a new letter instead]] and send the new one for approval.

## Good to know
- The app does not track the mailing. For certified mail, add the tracking number as a note on the case.
- Keep a copy of every letter you mail.
- Mailing from the app is not available yet. The steps above are the whole process.
