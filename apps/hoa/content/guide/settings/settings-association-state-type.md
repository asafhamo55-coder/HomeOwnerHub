The state and type you pick here decide which law HomeownerHub applies: the Georgia SB 406 checks, the registration kit, collections letters, late-fee caps and the State Law answers. Check them once when you start, and again if they were set wrong.

## Before you start
- Board members and admins can open this page. Only an **admin** can change it. A board member sees the values and is told to ask an admin.
- If your HOA has no association yet, an admin can create one on this page. It opens the books too.

## Steps
1. Open **Settings**, then the **Association** tab.
2. Check **Association name**, **State** and **Type** (HOA, Condominium or Co-op).
3. Only if your declaration chooses another state's law, tick **Advanced: the governing law is a different state** and pick that state under **Governing-law state**. Otherwise the governing law follows the state.
4. If you changed the state, the governing-law state or the type, select [[Review changes]]. A **What changes** box lists what switches.
5. Read it, then select [[Confirm and save]]. Select [[Back]] to change your mind.

A name-only change saves straight away with [[Save]].

## What happens next
- The pages that depend on the state switch right away: Georgia SB 406 checks and the registration kit, collections letters, the late-fee cap, condo or HOA law, and the State Law answers.
- Nothing already recorded is rewritten. Dues, payments, violations, meetings and documents stay as they are.
- A saved late-fee policy stays saved, but check it on the **Late fees** tab, because the cap may now be different.
- The change is written to the activity log with the old and new state and type codes.
- Renaming the association does not change the Zelle memo code residents already use.

## If something goes wrong
- "Only an admin of your HOA can change the association’s state or type.": you are a board member. Ask an admin.
- "Check the highlighted fields.": a name is too short or a state is missing. The message under the field says which.
- "Couldn’t save the association. Try again.": nothing changed. Save again.

## Good to know
- If your organization has more than one association, each has its own card. Change and confirm each one separately.
- A state with no loaded rules still saves. The pages then say HomeownerHub has no rules for it and point you to your governing documents.
- The set-up checklist on the dashboard links here: **Confirm your state and association type**.
